📌 Instruções de uso do NutriCare
Baixe o aplicativo
Acesse o repositório no GitHub e faça o download dos arquivos (botão “Code” → “Download ZIP”).
Extraia os arquivos
Após o download, localize o arquivo .zip e extraia seu conteúdo para uma pasta de sua preferência.
Abra o aplicativo
Dentro da pasta extraída, localize o arquivo index.html.
Execute no navegador
Clique duas vezes no arquivo index.html ou abra-o manualmente em qualquer navegador (Google Chrome, Edge, etc.).

⚠️ Observações importantes
O aplicativo funciona diretamente no navegador, não precisa instalar nada
Certifique-se de manter todos os arquivos na mesma pasta (se sair movendo coisa, vai quebrar mesmo)
Recomendado usar navegadores atualizados para melhor desempenho
